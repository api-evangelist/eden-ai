Eden AI is a French AI gateway that puts one API, one key and one invoice in front of 500+ AI models from 50+ providers. Its v3 surface is deliberately OpenAI-wire-compatible — chat completions, responses, embeddings, moderations, images and audio — with an Anthropic Messages pass-through alongside it, so existing SDK code moves over by swapping a base URL. A single model-routed Universal AI endpoint covers the expert models that are not LLMs: OCR and document parsing, image and video analysis, speech, translation, text analysis and web research, synchronously or as async jobs with signed webhooks. Routing, provider fallback, response caching, per-key budgets, guardrails and per-request cost reporting are built into the gateway, and an EU endpoint restricts processing to providers cleared for European data residency.

**Areas:** Artificial Intelligence · AI Gateway · LLM · Machine Learning · OCR · Translation · Speech · Computer Vision · MCP · Emotion Detection

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Eden AI: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
